# Noki 使用者歷程（User Journeys）

> 本文承 `product-architecture.md`，把 MVP 範圍展開成**不同角色的完整端到端旅程**，作為後續畫面流程 / PRD 的依據。
> 日期：2026-06-25 · 對應 MVP（Phase 0）已定案範圍。

## 0. 範圍與前提（讀前必看）
- **多教練**：MVP 即含小工作室多教練（主理人 + 教練角色權限）。
- **金流不進 MVP**：收款由教練/主理人**自行對帳（手動標記已收款）**，無線上金流。
- **飲食只做「互動交流」**：MVP 不做拍照辨識與營養素追蹤；飲食 = 教練↔學員的訊息/問答 + 文字飲食筆記。Phase 2 才加拍照辨識。
- **三面**：① Web 後台（教練/主理人）② Agent 對話窗口（教練端為主）③ 學員端（跑在 LINE LIFF，零安裝）。
- 本文角色化名：主理人 **Nina**（Noki Studio）、教練 **Max**、學員 **小明 / 小美**。

---

## 1. 角色與權限速覽

| 角色 | 是誰 | 主要載具 | 看得到的範圍 | 不能做 |
|------|------|---------|------------|--------|
| **主理人 Owner**（Nina） | 工作室負責人，常身兼教練 | Web 後台（主）+ Agent + LINE | **全店**：所有教練、學員、排課、合約、營收對帳、教練績效 | — |
| **教練 Coach**（Max） | 受雇/合作教練 | Web 後台 + Agent + LINE | **自己的**學員、課表、行程、紀錄；唯讀自己的績效 | 看不到別的教練的學員財務細節、不能改全店設定 |
| **學員 Member**（小明） | 上課的會員 | **LINE（LIFF 學員端）** | 自己的今日課表、訓練紀錄、成長、與教練對話、剩餘堂數 | 看不到後台 |
| 獨立教練（= Owner+Coach 合一） | 無工作室的自由教練 | 同上，但一人扮兩角 | 全部（因為就他一人） | — |

> 權限原則：主理人 ⊇ 教練 ⊇ 學員。MVP 用「店 → 教練 → 學員」三層資料邊界。

---

## 2. 共同起點：身分與 LINE 綁定

所有角色第一次都要把身分接起來。學員這一步尤其關鍵——**走 LINE、零安裝**。

| 步驟 | 角色 | 面 | 發生什麼 |
|------|------|----|---------|
| 1 | 教練/主理人 | Web | 用 Email 或 LINE Login 註冊，建立或加入工作室 |
| 2 | 學員 | LINE | 掃工作室 QR / 點教練連結 → **加 LINE 官方帳號好友** |
| 3 | 學員 | LINE LIFF | 點 Rich Menu → 開 LIFF → `liff.getProfile` 自動帶入 LINE 身分 → 與教練給的學員檔案綁定（`account link`） |
| 4 | 學員 | LINE | 完成，之後從 LINE 聊天室置底選單即可進入，無需帳密、無需下載 App |

> 痛點對應：移除「下載 App + 註冊」這個最大流失點（直接打掉 OneFloors iOS-only 的門檻）。

## 3. 主理人歷程（Owner / Nina）

### J1 — 開店上手（Onboarding，目標：3 步 30 分鐘能用）
| 步驟 | 做什麼 | 面 |
|------|--------|----|
| 1 | 建立工作室：名稱、營業時間、場地、品牌色 | Web |
| 2 | **邀請教練**：輸入 Max 的 Email/手機 → 發邀請 → Max 加入並取得教練權限 | Web |
| 3 | 設定方案與時段：課程類型（1對1/團課）、堂數方案、可預約時段規則 | Web |
| 4 | 連結 LINE 官方帳號、設定 Rich Menu（今日課表/我的進度/預約/聯絡教練） | Web |
| 5 | 匯入既有學員（手動或批次）、建立合約堂數 | Web / Agent |
- **Agent 捷徑**：「新增教練 Max，手機 09xx」「建立一個 10 堂私教方案 12000 元」一句完成。
- 痛點對應：對標 SimpleTraining「3 分鐘上手」，但多教練 + LINE 一次設好。

### J2 — 每日經營巡檢（目標：晨間 2 分鐘掌握全店）
| 步驟 | 做什麼 | 面 | 系統回應 |
|------|--------|----|---------|
| 1 | 早上打開儀表板 | Web | 今日全店堂數、各教練行程、今日到期合約、待跟進名單 |
| 2 | 問 Agent「今天店裡幾堂課？哪個教練滿？」 | Agent | 跨教練彙總回覆 |
| 3 | 看「**流失預警**〔規則版〕」：堂數將盡或久未出席的學員 | Web | 清單 + 一鍵「請教練關心」 |
| 4 | 處理跨教練調度（見 J4） | Web/Agent | — |

### J3 — 月底結算（無線上金流，手動對帳）
| 步驟 | 做什麼 | 面 |
|------|--------|----|
| 1 | 看本月各教練完課數、消課數、續約率 | Web |
| 2 | 收款**自行對帳**：把實際收到的款項在合約上「標記已收款 / 部分收款」 | Web |
| 3 | 匯出本月概況（堂數/續約）供自己記帳 | Web |
- 註：業績抽成/薪資自動計算為 Phase 1.5；MVP 提供數據，計薪先人工。

### J4 — 多教練衝堂 / 調課（多教練特有）
| 情境 | Noki 行為 |
|------|----------|
| Max 排課撞到場地/時段被佔用 | 排課時即時**衝堂偵測**擋下，提示可用時段 |
| 教練臨時請假 | 主理人在行事曆把該教練當日課改派或通知學員改期；Agent：「把 Max 明天的課都改到後天同時段並通知學員」 |
| 教練離職 | 學員「轉移」給另一位教練，歷史紀錄與合約跟著移轉（見 §8 邊界情境） |

## 4. 教練歷程（Coach / Max）

### J1 — 接手新學員（試課 → 簽約 → 排課 → 指派課表）
| 步驟 | 做什麼 | 面 | 重點 |
|------|--------|----|------|
| 1 | 收到試課諮詢（來自品牌頁表單 / LINE） | Web/LINE | 線索進 CRM |
| 2 | 排一堂體驗課 | Agent | 「幫陳小美約這週六下午兩點體驗課」 |
| 3 | 試課後簽約 | Web/Agent | 「小美簽 10 堂私教，今天先收 5000 訂金」→ 合約建立、標記部分收款 |
| 4 | 指派課表 | Web/Agent | 「把『增肌入門 8 週』指派給小美」從模板套用 |
| 5 | 小美收到 LINE 通知 + Rich Menu 可看課表 | LINE | 學員零安裝接上 |

### J2 — 上課當下（簽到 → 消課 → 記錄）
| 步驟 | 做什麼 | 面 | 重點 |
|------|--------|----|------|
| 1 | 學員到場掃 QR 簽到 | LINE LIFF `scanCodeV2` | 自動扣 1 堂、合約剩餘更新 |
| 2 | 帶課，邊練邊記每組重量/次數 | Web/手機 | 課表預填建議重量，點一下完成該組 |
| 3 | 課中看「**本次 vs 上次**」 | Web | 即時知道該不該加重量 |
| 4 | 課中留言給學員（鼓勵/提醒） | Web/LINE | 進學員時間軸 |

### J3 — 課後跟進（Agent 一句話收尾）
| 步驟 | 做什麼 | 面 |
|------|--------|----|
| 1 | 課後用一句話補記 | Agent：「小明今天深蹲 100x5 完成，狀況好，下次加 5 公斤」 |
| 2 | Agent 回顯確認 → 執行 → 寫紀錄 + 調下次課表 + （可選）通知小明 | Agent |
| 3 | 一鍵發週摘要 / 鼓勵訊息 | Agent/LINE |

### J4 — Agent 跨模組（經營副駕，最尖銳體驗）
> 教練打一句話，Agent 跨「合約 + 紀錄 + 排課 + 訊息」一起處理。

```
Max：小明剩幾堂？最近有進步嗎？
Agent：小明剩 2 堂，合約 6/30 到期。深蹲近 4 週持平、出席率下降（上週缺 1）。
        ⚠️ 續約風險偏高。
Max：那幫我約一次續約聊聊，並把他這季數據整理給我。
Agent：我要做這些 —— ①週四 19:00 排「續約諮詢」给小明 ②整理近 12 週訓練+體態摘要
        ③發 LINE 提醒小明。確認？
Max：確認
Agent：✅ 已排課、已生成摘要（點此看）、已發送提醒。
```

### J5 — 個人品牌與招生
| 步驟 | 做什麼 | 面 |
|------|--------|----|
| 1 | 選版型生成個人品牌頁（經歷/方案/學員成果/預約） | Web |
| 2 | 把頁面連結 / LINE 分享出去 | LINE `shareTargetPicker` |
| 3 | 潛在學員填表 → 進 CRM 成線索 → 回到 J1 | Web |

## 5. 學員歷程（Member / 小明）— 全程在 LINE

### J1 — 加入（零安裝）
加 LINE 好友 → Rich Menu → LIFF 自動帶身分綁定 → 看到「今日課表」。**全程不下載 App、不設密碼。**

### J2 — 上課日
| 步驟 | 做什麼 | 面 |
|------|--------|----|
| 1 | 課前收到提醒 push「今晚 7 點 Max 的課」+ 一鍵確認/改期 | LINE |
| 2 | 到場掃 QR 簽到 | LINE LIFF |
| 3 | 課中/課後看今天課表與完成情況 | LINE LIFF |

### J3 — 自主訓練 / 居家
自己用 LINE LIFF 記錄訓練、查「本次 vs 上次」、看動作說明；或用 Agent：「深蹲三組做完了」。

### J4 — 互動交流（MVP 的「飲食」就在這裡）
| 情境 | 做什麼 | 面 |
|------|--------|----|
| 問教練問題 | LINE 直接傳訊（「今天外食吃什麼好？」） | LINE |
| 記飲食 | 用**文字筆記**記一餐（非拍照辨識） | LINE LIFF |
| 教練回饋 | 教練看到筆記/訊息，給建議 | Web→LINE |
> 註：MVP 飲食 = 對話 + 文字筆記；拍照辨識/營養素追蹤是 Phase 2。

### J5 — 看見成長（留存王牌）
| 步驟 | 做什麼 | 面 |
|------|--------|----|
| 1 | 隨時看 12 週折線（各動作/體態） | LINE LIFF |
| 2 | 每週收到「週摘要」push（出席/完成/變化） | LINE |
| 3 | 季度收到 AI 成長敘事（把數據講成一段話）〔Phase 2 強化版〕 | LINE |

### J6 — 續約 / 轉介
堂數將盡 → 收到續約提醒 → 與教練約聊 → 續約；滿意則用 `shareTargetPicker` 把教練分享給 LINE 好友。

## 7. Agent 對話實例集（concrete）

**教練端（寫）**
- 「幫王小明這週三、五早上各排一堂」→ 排課（確認後執行）
- 「把小明深蹲加 5 公斤、臥推改 4 組」→ 改課表
- 「小明今天的課做完了，狀況不錯」→ 消課簽到 + 記錄
- 「提醒明天 7 點的學員帶毛巾」→ 群發 push

**教練端（讀/跨模組）**
- 「這週誰快流失？」→ 規則版風險清單
- 「小美還剩幾堂、何時到期？」→ 合約查詢

**學員端（LINE）**
- 「幫我約 Max 這週的課」→ 預約
- 「我這個月進步多少？」→ 回成長摘要
- 「今天有點累，可以調整嗎？」→ 轉教練 / 給建議（互動交流）

> 所有「寫」動作：Agent 先回顯要做什麼 → 確認 → 執行 → 留痕可撤銷（設計原則 #3）。

## 8. 邊界 / 例外情境（MVP 要想清楚）

| 情境 | Noki 處理 |
|------|----------|
| **排課衝堂** | 即時偵測擋下 + 建議可用時段 |
| **學員改期/取消** | LINE 一鍵改期；自訂取消政策（太晚取消是否扣堂） |
| **爽約缺席** | 標記未到；是否扣堂依規則；觸發關心訊息 |
| **堂數用盡** | 自動停止可預約 + 觸發續約提醒鏈 |
| **部分收款 / 欠款** | 合約上手動標記「已收 / 部分 / 未收」（無線上金流） |
| **教練離職交接** | 學員批次轉移給新教練，合約 + 歷史紀錄跟著轉，學員收到 LINE 通知 |
| **同名學員** | Agent 反問澄清（哪一位「小明」） |
| **Agent 解析錯誤** | 確認步驟攔截；錯了可撤銷（audit log） |
| **學員沒用 LINE** | 退化路徑：教練代記錄 + 用簡訊/電話（少數，MVP 可接受） |

## 9. 對照：每個歷程解掉的競品痛點
- 學員 LINE 零安裝 → 解 OneFloors（iOS-only）、一般 App 的下載流失
- 多教練排課協作 + 衝堂 → 對標 SimpleTraining，但 LINE 化
- Agent 一句話跨模組記錄/調課/通知 → **全市場 0 家**（見架構 §6）
- 成長敘事 push → 攻續約率/推薦率痛點（研究：國內 68% vs 國外 85%）
- 手動對帳 → MVP 先輕量、不被金流串接拖慢上線

> 下一步可選：① 針對任一歷程畫**線框圖 / 畫面流程** ② 把「多教練權限模型」或「LINE LIFF 學員端」寫成細部 PRD ③ 定義 Agent 的 Action/意圖 schema。
